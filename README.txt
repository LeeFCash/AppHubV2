for arch linux steps to get working 
step 1:
	open terminal and enter => sudo pacman -S python-flask   
step 2:
	open terminal and enter => sudo pacman -S python
step 3:
	open terminal and enter => sudo pacman -S jdk-openjdk
step 4:
	go to appHubV2 dir by using => cd /path/to/appHubV2
step 5:
	enter => javac *.java
step 6:
	enter => java AppLauncherUI
at this point you should be done with the install and have the app launcher open.
